# 出陣ベル 利用マニュアル

同時着弾のための共通カウントダウンBotです。

**全員に同じカウントが流れます。自分の行軍時間の数字が読まれたら出陣してください。**
行軍40秒の人は「40」で、52秒の人は「52」で出ます。
カウント側は誰が何秒かを知る必要がありません。

---

## 使う前に

### 1. ノリーに連絡する

Botはノリーのパソコンで動いています。**使いたいときは事前に伝えてください。**

起動していないとボタンを押しても
「出陣ベルBotは時間内に応答しませんでした」と表示されます。
故障ではなく、単に立ち上がっていないだけです。

### 2. ボイスチャンネルに入る

入っていない状態で押すと「先にボイスチャンネルに入ってください。」と返ります。

**カウントが始まる前に全員入っておいてください。**
途中で入退室すると、読み上げBotの「○○さんが入室しました」が
カウントに重なる可能性があります。

---

## 使い方

### 基本：パネルのボタンを押す

チャットに `/panel` と入力するとパネルが出ます。

```
出陣カウントダウン
いまの設定：20 まで数える（○○ が変更）

[ 終わりの秒数を選ぶ ▼ ]
[ 80秒 ] [ 75秒 ] [ 70秒 ] [ 65秒 ] [ 60秒 ]
[ 55秒 ] [ 50秒 ] [ 45秒 ] [ 40秒 ]
[ 止める ]
```

#### 1. 終わりの秒数を選ぶ（戦闘の前に一度だけ）

一番上の欄で **「何秒まで数えるか」** を選びます（0〜50、5秒刻み）。

**参加者の中で一番行軍が短い人**に合わせてください。
一番短い人が30秒なら「30 まで数える」にします。それより下の数字は誰も使わないので、
全員が出たところで自動的に終わります。

- 選んだ値はパネルに表示され、**Botを再起動しても残ります**。毎回選び直す必要はありません
- **設定はサーバーで共通**です。誰かが変えると全員のボタンに反映されます。押す前に「いまの設定」を見てください
- 選んだ秒数以下のボタンは**灰色になって押せなくなります**（「40 まで」なら 40秒ボタン）

#### 2. 秒数のボタンを押す

**参加者の中で一番行軍が長い人**をカバーする秒数を押してください。
そこから、選んだ終わりの秒数まで数えます。

- **誰が押してもOK**です
- パネルは一度置けば**そのまま残ります**。毎回 `/panel` を打つ必要はありません
- ボタンの秒数は**作成済み**なので、終わりの秒数を変えても待ち時間はありません
- 押し間違えたら**赤い「止める」ボタン**で止めて、すぐ押し直せます

#### 押したあとの流れ

1. 出陣ベルがボイスチャンネルに入ってくる
2. 3秒後に「よーい」の合図
3. カウント開始。**自分の秒数で出陣**
4. 選んだ終わりの秒数まで読むと自動で退出する

流し始めるときに **「40 → 20 を流します」** と表示されます。
終わりの秒数が思っていたものと違ったら、止めて選び直してください。

> 選択欄が無い古いパネルでもボタンは動き、サーバーの設定どおりに数えます。
> 選択欄を使いたいときは `/panel` を打ち直してください。

### 選択肢にない秒数を使いたいとき

チャットに `/countdown` と入力すると、秒数の入力欄が出ます。

| 入力欄 | 意味 |
|---|---|
| **start** | 開始する残り秒数 |
| **end** | 終了する残り秒数。0まで読むなら `0` |

**どちらも必ず入力してください。**
入力欄をタブで移動して、start と end の両方に数字を入れます。
片方だけ入れて送信できないようになっています。

参加者の行軍が40〜65秒に収まっているなら、
`start=65` `end=40` にすれば**65から40まで**を読んで終わります。

`/countdown` は**パネルの「終わりの秒数」とは関係なく**、入力した end まで読みます。

流し始めるときに **「65 → 40 を流します」** と表示されます。
**入力した数字と合っているか、ここで必ず確認してください。**

#### 待ち時間について

| 使い方 | 待ち時間 |
|---|---|
| **パネルのボタン** | **なし。**終わりの秒数を変えても、押せばすぐ始まります |
| `/countdown` で、すでに作ってある秒数 | なし |
| `/countdown` で、初めて使う秒数 | 音声を作る時間だけ待ちます |

**待ち時間が出るのは、`/countdown` で初めての秒数を指定したときだけ**です。
一度作れば残るので、2回目からはゼロになります。

作る時間は読む数字の個数でほぼ決まります（1個あたり約0.9秒）。

| 範囲 | 読む数字 | 作る時間 |
|---|---|---|
| 60→40 | 21個 | 約20秒 |
| 65→40 | 26個 | 約26秒 |
| 45→0 | 46個 | 約40秒 |
| 60→0 | 61個 | 約55秒 |

**この音声作成にはノリー側で別のソフトを立ち上げておく必要があります。**
初めての秒数を使う予定があるなら、**当日ではなく事前に伝えてください。**
用意しておけば待ち時間ゼロで始められます。

## 注意事項

### 同時に流せるのは1本だけ

**1つのサーバーで、同時に鳴らせるカウントは1本だけです。**
Botはボイスチャンネルを1つしか掴めないためです。

- 再生中に別の人が押すと「いま再生中です。」と返ります
- 再生していないときに別のボイスチャンネルから押すと、Botはそちらへ移動します

複数の部隊が別々のタイミングで出たい場合は、**順番に使ってください。**

### ゲーム内の時間とはコンマ数秒の差が出ます

ゲームが表示する行軍時間は秒単位に丸められていることがあり、
出陣を押してから実際に部隊が動き出すまでにも僅かな差があります。

**カウントは着弾を揃えるための目安で、完全にゼロ誤差にはなりません。**
数秒単位でバラついていたものがコンマ数秒に収まる、くらいの精度と考えてください。

## 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 「時間内に応答しませんでした」 | Botが起動していません。ノリーに連絡してください |
| 「先にボイスチャンネルに入ってください。」 | ボイスチャンネルに入ってから押してください |
| 「いま再生中です。」 | 誰かが使用中です。終わるまで待つか、赤い「止める」で止めます |
| ボタンが灰色で押せない | 終わりの秒数がそのボタン以上になっています。一番上の欄で下げてください |
| 「数えられません」と出る | 同上です。表示が古いパネルから押すと、灰色になっていなくてこの案内が出ます |
| 「音声を用意できませんでした」 | 未作成の秒数です。ノリーに用意を依頼してください |
| 音が聞こえない | Discordの音量設定と、Botがミュートされていないか確認 |
| 途中で止めたい | 赤い「止める」ボタンか、`/stop` と入力するとBotが止まって退出します |

## コマンド一覧

| コマンド | 用途 |
|---|---|
| `/panel` | ボタンと終わりの秒数の選択欄を設置する（一度置けば残ります） |
| `/countdown` | 秒数を指定して流す |
| `/stop` | 再生を止めて退出させる |
